## DayLight Blog – Full-Stack Blog Application

* Developed and deployed a full-stack blog application using Python and Flask, featuring user registration, authentication, and session management.

* Implemented secure password hashing and authentication workflows using Flask-Login and Werkzeug.

* Designed an administrative access control system using a custom Python decorator to restrict blog post creation, editing, and deletion to authorized administrators.

* Developed a commenting system that allows authenticated users to interact with blog posts.

* Integrated SQLAlchemy ORM for database management and migrated the application from SQLite to PostgreSQL for production deployment.

* Built dynamic web interfaces using Bootstrap, WTForms, Jinja2, and Flask-CKEditor.
